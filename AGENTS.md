# NavTasks — начало работы

**Не использовать main как актуальную базу beta.** Main содержит исторический исходник; актуальная документация ведётся независимо от APK.

1. Через подключённый GitHub открой ветку [docs/navtasks-development](https://github.com/sergbokarev95-arch/NavTasks/tree/docs/navtasks-development).
2. Прочитай [обязательный регламент AGENTS.md](https://github.com/sergbokarev95-arch/NavTasks/tree/docs/navtasks-development/AGENTS.md) и [HANDOFF.md](https://github.com/sergbokarev95-arch/NavTasks/tree/docs/navtasks-development/docs/development/HANDOFF.md), CURRENT_STATE.md, NEXT_TASKS.md, DECISIONS.md в этой ветке.
3. Проверь реальные feature branches, Actions, Releases, SHA и versionCode. Продолжи незавершённый run. Не запускай повторно активную сборку и не меняй HEAD во время публикации.
4. Выполни полный цикл согласованной разработки, показывай фактические промежуточные этапы, проверь опубликованный APK, дай ссылку. При техническом ограничении укажи его и точный статус.
5. Веди актуальный контекст только в docs/navtasks-development, не дублируй историю во все файлы. Stable OTA, исходники main и signer не менять без согласия.

Старые документы в main являются архивными, а не текущими инструкциями. Этот указатель — только документация, без изменения приложения.
