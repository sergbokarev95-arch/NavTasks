# NavTasks 0.2 beta

Офлайн-планировщик задач и чек-листов для судового офицера.

## Реализовано в 0.2

- Компактный экран «Сегодня»: прогресс, семь дат для быстрого переключения, просроченные задачи отдельно, круглые отметки и вложенные чек-листы внутри карточки.
- Выполненные задачи переходят в раскрываемую стопку с анимацией. Все вложенные пункты автоматически завершают основную задачу.
- Экран «План»: год → месяц → день и навигация по календарю.
- Экран «Задачи»: постоянно видимые категории Daily, Weekly, Monthly, Extra и полноэкранный редактор.
- Периодичность «по календарю» или «от фактического выполнения» отдельно для каждой задачи.
- Срок до конца дня либо конкретное время; по умолчанию используется местная дата и часовой пояс **телефона**, без отдельного судового UTC.
- Перенос на другую дату сохраняет первоначальную дату и историю. Задача отображается с пометкой «Перенесено» и входит в прогресс выбранного дня.
- Пропуски накапливаются по исходным датам; следующая календарная копия появляется независимо от старого пропуска. На уровне задачи доступны: накопить, автоматический перенос, спросить, архивировать.
- Закрытие задачи с причиной; локальное сохранение при каждом действии.
- День / ночь / системная тема, русский и английский интерфейс. Названия, которые написал пользователь, не переводятся автоматически.
- Системные уведомления Android: напоминания, однократное уведомление о пропуске, ежедневная сводка пропущенных (по умолчанию в 08:00, только при наличии пропусков).
- Два интерактивных виджета рабочего стола, компактный и широкий. Простые задачи можно отметить в виджете, сложные открывают чек-лист в приложении.
- Адаптивная иконка Minimal Glass с цветной и монохромной версиями.

## Установка и тестирование

Тестовый вариант имеет **applicationId `com.navtasks.app.beta`** и название **NavTasks β**. Он устанавливается **рядом с NavTasks 0.1**, не заменяет её и не использует её данные. Это сделано специально, чтобы тестирование нового интерфейса не повредило существующие задачи.

На Android 13+ требуется разрешить уведомления. Для напоминаний точно в минуту на Android 12+ может потребоваться разрешение «Будильники и напоминания» в системных настройках. При отсутствии доступа используется системное неточное планирование.

Виджеты добавляются через меню виджетов рабочего стола. На разных лаунчерах визуальные эффекты и размеры могут отличаться; MagicOS 11 ещё нужно протестировать на реальном HONOR.

## Ограничения тестовой версии

- Реальный нативный HONOR Liquid Glass SDK пока не подключён; используется собственная полупрозрачная стилизация.
- Android и энергосбережение производителя могут задерживать фоновые события. Надёжность уведомлений на HONOR необходимо испытать отдельно.
- Не реализованы резервное копирование/импорт, синхронизация устройств и полноценный экран истории закрытых задач.
- Примерные пункты проверок не являются официальной процедурой GMDSS или требованиями компании; пользователь редактирует их под свои документы.
- APK не тестировалась на физическом устройстве в среде сборки; нужны испытания пользователя.

## Сборка

Android SDK 36, JDK 17, Gradle 8.13; Kotlin + Jetpack Compose (без Flutter/WebView).

```bash
gradle assembleDebug testDebugUnitTest
```

Зависимости загружаются из Google Maven и Maven Central при первой сборке. Исходники включают XML для адаптивной иконки и обоих AppWidgetProvider.
